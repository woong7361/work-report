# 발견 사항

리팩터링 중 확인했지만 동작 변경을 피하기 위해 고치지 않은 사항을 적는다.

- 페이지를 외부 자산으로 분리하면 계획에 적힌 인라인 `<script>` 추출 검증 명령은 대상이 없다. 렌더링된 `app.js`, `app-ui.js`, `app-setup.js`를 각각 파일로 만든 뒤 `node --check`로 검사하는 방식으로 같은 검증을 수행한다.
- `_env.ps1`의 오류 기록 책임은 계획의 모듈 목록에 이름이 없었다. 경로·설정·에이전트 홈만 남긴다는 경계를 지키기 위해 `_errors.ps1`을 별도 모듈로 두었다.
- PMS 수집·일감 파일 쓰기는 기존처럼 `io.open(...).write(...)`를 직접 호출해 인터프리터 경고 모드에서 `ResourceWarning`을 낸다. 파일 닫기 방식 변경은 동작 범위를 넓히므로 이번 구조 이동에서는 건드리지 않았다.
