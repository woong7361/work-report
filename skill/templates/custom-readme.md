# 내 양식

이 폴더의 파일로 보고서를 회사 양식과 우리 문체에 맞출 수 있다.
**업데이트해도 이 폴더는 덮어쓰지 않는다.** 제거해도 남는다.
(`uninstall.ps1 -PurgeReports`는 보고서 폴더를 통째로 지우므로 이 폴더도 함께 사라진다.)

| 파일 | 하는 일 |
|---|---|
| `report-format.md` | 보고서 양식을 **통째로 바꾼다** |
| `writing-rules.md` | 기본 글쓰기 원칙 **뒤에 덧붙인다** |

## 켜고 끄는 법

뷰어(시작 메뉴의 `work-report`)의 **설정**에서 켠다.

- `내 보고서 양식 쓰기`
- `내 글쓰기 문체 쓰기`

**켜는 순간 기본값이 이 폴더에 복사된다.** 왼쪽 아래 `내 양식`에서 열어 고치면 된다.
끄면 기본값으로 돌아가고, 고쳐 둔 파일은 지워지지 않는다. 다시 켜면 그대로 쓴다.

## 알아 둘 것

- **꺼 두는 것이 기본이다.** 그래야 양식이 좋아질 때마다 업데이트로 따라온다.
  켜는 순간 그 파일은 그 시점에 멈춘다.
- 켜 둔 파일이 비었거나, 내용이 거의 없거나, 글자가 깨지면 **기본값으로 돌아간다.**
  왜 그랬는지는 그날 `raw` 폴더의 수집 결과 맨 위에 적힌다.
- 켜 두었는데 파일을 지우면 다음 실행이 기본값으로 다시 만든다.
- 아래 넷은 여기서 바꿀 수 없다. 바꿀 수 있으면 자동 실행이 망가진다.
  - 확인 질문을 하지 않는 것
  - 근거 없는 내용을 쓰지 않는 것
  - 보고서를 저장하는 경로
  - 파일 변경을 근거로 다루는 법
